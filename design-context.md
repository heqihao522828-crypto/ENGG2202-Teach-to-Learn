# Design context

This repository is a fork of the HKU Engineering Active Learning website. It is being adapted into an ENGG2202-focused Teach-to-Learn microsite.

## Preserve from the parent site

- Next.js static-export architecture and GitHub Pages deployment workflow.
- Responsive, accessible navigation patterns.
- HKU Engineering identity and connection to the wider Active Learning initiative.
- Real student and workshop photography.

## Change for this microsite

- Remove course schedules, class logistics, and ENGG1101 navigation from the primary experience.
- Lead with Teach to Learn as the learning proposition.
- Present Green Technology and the SDGs as the current ENGG2202 project theme, not as the universal name of the framework.
- Make the six-stage project journey, active-learning evidence, Notion guides, and student project gallery the primary destinations.
- Support future project cards without redesigning the page.

## Audiences

1. ENGG2202 students starting and developing a project.
2. Teaching staff reviewing the learning model and student evidence.
3. External visitors exploring student work and the Teach-to-Learn approach.
