# Start here

Use this guide to find the task, evidence and resources for the Gate your team is working on. You do not need to read every page or use every tool.

## The six Gates

| Gate | Team decision | Required outcome |
| --- | --- | --- |
| 01 Focus | Which Green Technology challenge is worth investigating? | A provisional challenge direction |
| 02 Define | Is the problem real, important and bounded? | A problem statement supported by evidence |
| 03 Plan | Which route should the team pursue? | A justified concept and workable project plan |
| 04 Learn | What can we learn from existing work and a first working version? | An inspectable build and reproducible record |
| 05 Improve | What should the evidence make us change? | Test evidence, revision and retest |
| 06 Contribute | What can another person use or continue? | A responsible public contribution |

The Gates are project decisions, not six separate projects. New evidence may send your team back to an earlier decision.

## Where work belongs

| Place | Use it for |
| --- | --- |

| Ed Discussion | Gate checkpoint submissions and course questions |

## Work at each Gate

1. Do the investigation, design, build or test.
2. Keep the source, observation, data, version or feedback.
3. Use feedback to revise the project decision.
4. Update the repository.
5. Submit the checkpoint evidence listed on the Gate page.

## Using AI

AI may help you search, learn, plan, code, analyse or review documentation. It is not a source, stakeholder or test result.

For material AI use:

1. Keep the prompt or task.
2. Check important claims against original sources or project evidence.
3. Test generated code and calculations.
4. Record what the team used, changed or rejected.

Do not upload personal, confidential, commercially sensitive or restricted information. Do not invent interviews, observations, measurements, sources or test results.

Use the [AI and Digital Tools quick reference](resources-ai-and-digital-tools.md) to choose a tool.

## Before Gate 01

- Confirm the team and communication channel.
- Create the team GitHub repository.
- Add a short `README.md` and an `evidence/` folder.
- Add a simple AI-use log if the team uses AI materially.
- Open Gate 01 and discuss possible challenge directions together.
