# Gate 06: Contribute

## Decision

What can another person now use, learn from or continue?

Choose one final output for a defined audience. The output may be a working system, teaching resource, film, demonstration, competition entry or public repository.

## What to do

1. Define the audience and what they should be able to do.
2. Ask a real audience member to use or respond to the output.
3. Revise it from the observed questions or difficulty.
4. Complete the release, privacy, safety and attribution checks.
5. Create a named GitHub release.
6. Write a bounded contribution statement.

## Public repository checklist

- project purpose, stakeholder and context;
- SDG target connection;
- current version and status;
- setup, build or use instructions;
- architecture or workflow;
- test summary and evidence links;
- limitations and safe-use conditions;
- licence and third-party attribution;
- editable source files;
- release notes and next step.

Before publishing, remove personal data, credentials and files the team does not have permission to release. Check Git history for exposed secrets and rotate any credential that was committed.

## Contribution statement

> Our team contributes [resource or system] for [audience]. It supports [bounded use] under [conditions]. The strongest evidence is [link]. It should not be used or interpreted as [limitation]. A future team could continue by [next step].

## Checkpoint submission

Submit one team post on Ed Discussion with:

1. audience and contribution;
2. final output and public repository;
3. audience interaction, feedback and revision;
4. strongest evidence and bounded claims;
5. known limitations and next step;
6. licence, attribution, privacy, safety and secret review;
7. release tag and release notes;
8. final reflection on what changed in the team's understanding.

## Ready for review

- A real audience can use or learn from the output.
- Feedback caused a visible revision.
- The released version is identifiable.
- Claims match the evidence and conditions.
- Ownership, licence, attribution, privacy and safety are checked.
- Another person can see how to continue the work.
