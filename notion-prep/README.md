# ENGG2202 Teach to Learn · Notion Student Workspace

This folder contains the English, student-facing material prepared for the
Notion workspace. It is deliberately separated from the public website:

- the website shows the complete ENGG2202 approach and project journey;
- Notion releases the detailed working guide one Gate at a time;
- Moodle / Ed Discussion carries formal dates, submissions and grades;
- each team repository preserves the actual engineering work and evidence.
