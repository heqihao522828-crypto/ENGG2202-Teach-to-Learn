# ENGG2202 Teach to Learn · Notion Student Workspace

This folder contains the English, student-facing source material for the Notion
workspace. It is deliberately separated from the public website:

- the website shows the complete ENGG2202 approach and project journey;
- Notion releases the detailed working guide one Gate at a time;
- Moodle / Ed Discussion carries formal dates, submissions and grades;
- each team repository preserves the actual engineering work and evidence.

`course-material.csv` provides the compact Notion database structure and a
suggested year-long release rhythm. Replace dates there when the official course
calendar is confirmed. “Scheduled” is used for unreleased material: it tells
students that the route is intentionally timed, rather than suggesting that the
teaching team has not prepared it.

## Editorial rules

- Each Gate page contains five parts: decision, tasks, resources, checkpoint and readiness check.
- Give a resource only where it helps a named Gate task.
- Keep instructions short. Do not repeat general course philosophy on every page.
- AI tools may support the work, but original sources and project evidence remain necessary.
- GitHub stores the project's decisions, versions and evidence from Gate 01 onward.
- Ed Discussion carries checkpoint submissions. Moodle carries official assessment information.
