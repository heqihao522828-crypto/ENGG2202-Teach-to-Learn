# World Engineering Day and WFEO Hackathon

Use this resource to find an external challenge, compare your evidence with an international competition and, when a current cycle is open, consider a public project output.

## Current status

The 2026 WFEO Hackathon has concluded. The 2027 theme, dates and rules have not yet been announced. Check the official page before planning an entry.

## When it helps

| Gate | Use it for | Do not use it for |
| --- | --- | --- |
| 01 Focus | Browse challenge areas and write down a local question they raise | Copying a global brief as the project problem |
| 04 Learn | Compare how previous teams show development, testing and feasibility | Replacing study of relevant existing technical work |
| 05 Improve | Check whether the project shows a test, limitation and evidence-led change | Treating a polished video as test evidence |
| 06 Contribute | Consider a five-minute public video or current Hackathon entry | Replacing the repository, course checkpoint or individual report |

## Before entering a current Hackathon

1. Use the existing ENGG2202 project; do not start a second project for the competition.
2. Recheck eligibility, team size, dates, theme and submission format.
3. Obtain consent before submitting names, contact details, photographs or identifiable project material.
4. Complete the normal course evidence and submissions.
